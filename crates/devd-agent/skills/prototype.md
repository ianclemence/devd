# Prototype

1. Write down the one question the prototype answers and what result would decide it.
2. Build the least that can answer it. No tests, no polish, no error handling beyond what the question needs.
3. Run it and record the result.
4. Report the answer and the evidence. Delete the prototype, or keep it clearly labelled and outside the product. Never let a prototype become the implementation by drift; implement the decision properly.
