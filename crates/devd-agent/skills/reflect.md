# Reflect

Reviews a conversation or run for what cost time and proposes durable fixes. Skill and instruction changes affect every future agent, so nothing is applied without approval.

## When to use

After a run with repeated corrections, wrong assumptions or tool friction.

## Procedure

1. List the things that cost time: wrong assumptions, repeated corrections, tool friction.
2. Keep only lessons that are durable and not already covered.
3. Prefer structure over prose: if a check, type or test could enforce it, propose that (`plant-the-fix-in-the-structure`, `correct`). Only judgement calls become written guidance.
4. Propose each change to the person and apply only what they approve.

## Pitfalls

- Adding a rule to a skill for a one-off event.
- Applying changes before the person has answered.

## Verification

Each proposal names the evidence from the run, and only approved changes were made.
