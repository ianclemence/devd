# Reflect

1. Review the conversation or run for things that cost time: wrong assumptions, repeated corrections, tool friction.
2. Keep only lessons that are durable and not already covered.
3. Prefer structure over prose: if a check, type or test could enforce the lesson, propose that (`principle-encode-lessons-in-structure`, `correct`). Only judgement calls become written guidance.
4. Propose each change to the person and apply only what they approve. Skill and instruction changes affect every future agent.
