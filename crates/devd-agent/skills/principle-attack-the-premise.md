# Test whether the request is the right problem before solving it

Before building, ask whether the stated solution is the right one. What is the person actually trying to achieve? Is the constraint real? Is there a simpler way to the same outcome? Raise it once, briefly, with your recommendation, then proceed with the person's decision.
Smell: a large plan for a problem nobody confirmed.
