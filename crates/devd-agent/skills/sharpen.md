# Sharpen

Before planning an unfamiliar task, asks what an expert would do that the request does not mention, then restates the task to ask for exactly that. Decisions that belong to the person stay open.

## When to use

A task in a field you do not know well, or a request that is vague about method.

## Procedure

1. What would a top professional in this field do that is not being asked for?
2. What raw source material would they start from, rather than a summary of it?
3. Which specific methods and tools would they use?
4. What independent thing, other than you, would confirm the result is right?
5. Restate the task so it asks for exactly that.

## Pitfalls

- Making the task bigger. Deeper is not bigger.
- Deciding things that are the person's.

## Verification

The restated task names a source, a method and an independent check.
