# Sharpen

Before planning an unfamiliar task, ask what an expert would do that the request does not mention:

1. What would a top professional in this field do that is not being asked for?
2. What raw source material would they start from, not a summary of it?
3. Which specific methods and tools would they use?
4. What independent thing, other than you, would confirm the result is right?

Then restate the task so it asks for exactly that. Leave decisions that belong to the person open.
