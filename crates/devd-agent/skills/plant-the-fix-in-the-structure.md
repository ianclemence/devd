---
name: plant-the-fix-in-the-structure
description: Make the right thing easy and the wrong thing impossible instead of writing a rule about it
kind: build
roles: architect,reviewer,implementer
---

A lesson written in a document gets ignored. Put it in the structure: a type, a lint, a test, a single supported path, or deleting the example that gets copied. Write prose only for judgement calls nothing can enforce.

The failure this prevents: a rule in a README that was broken twice this month.
