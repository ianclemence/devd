---
name: report-numbers-honestly
description: A measurement is not a result until it says how it was taken and how much it varied
kind: check
roles: implementer,qa,reviewer
---

Report what was measured, how, how many samples, and the variation. Explain why the number is what it is, not only what it is. A suspiciously good number usually means the method is wrong.

The failure this prevents: "twice as fast" with no baseline.
