# Make the right thing the easy thing, and the wrong thing impossible

A lesson written in a document gets ignored. Put it in the structure: a type, a lint, a test, a single supported path, deleting the example that gets copied. Write prose only for judgement calls nothing can enforce.
Smell: a rule in a README that was broken twice this month.
