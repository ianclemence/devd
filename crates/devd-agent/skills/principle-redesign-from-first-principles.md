# Ask what the design should be if it started today, then decide how far to move

When a change fights the current design, ask what the design would be if built fresh for today's requirements. Then choose deliberately: the full redesign, the smallest step toward it, or leave it. Do not pile workarounds onto a shape that no longer fits.
