# Catch up

Read-only. Gather what happened since the person last looked (work finished, failures, approvals pending), check each item's current state rather than trusting earlier notes, then reply:

1. One sentence: what is waiting on them, or that nothing is.
2. A short summary, one line per item, each marked done, running, failed or not checked.
3. For each decision only they can make: your pick, the impact, the evidence, the risk.
4. Plain words. No hashes or paths unless needed. Never invent a number, link or action item.
